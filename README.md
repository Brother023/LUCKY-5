# Score Sheet Bot

A Telegram bot for tracking scores in games, sports, and challenges.

## Commands
- `/start` — Main menu
- `/newboard` — Create a scoreboard
- `/add Name` — Add a player
- `/score Name Points` — Update scores
- `/scores` — View standings
- `/reset` — Zero all scores
- `/help` — Instructions

## Deployment
Set `TELEGRAM_BOT_TOKEN` as an environment variable on Railway.
